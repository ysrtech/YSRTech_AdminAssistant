category: Content

---
1. [CMS > Pages](admin:cms_page) > **Add New Page** (or open one to edit).
2. **Page Information**: **Page Title**, **URL Key** (the address: `about-us` becomes /about-us), **Store View**, **Status** Enabled.
3. **Content**: the text. **Show / Hide Editor** switches between the visual editor and HTML. **Insert Widget** adds product rows and other blocks ([[widgets]]); **Insert Image** adds a picture from the media library.
4. **Design**: **Layout** (one column, with sidebars…).
5. **Meta Data**: keywords and description for search engines.
6. **Save Page**.

The home page is the CMS page chosen under **System > Configuration > Web > Default Pages > CMS Home Page**.
