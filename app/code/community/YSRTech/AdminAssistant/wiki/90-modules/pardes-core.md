Changes made for this store:

- **Newest First**: product listings sort newest first by default. It also appears as a choice in each category's **Display Settings** and in **Catalog > Frontend > Product Listing Sort by**.
- **Newsletter emails**: the "you are now subscribed" and "you have been unsubscribed" emails are not sent. The confirmation request still is.
- **Canadian taxes**: GST and QST show as separate lines, with QST on the running total ([[taxes]]).
- **Email Campaigns**: two starter templates under **Pardes newsletters**, and Pardes colours and fonts as the brand defaults ([[email-campaigns-templates]]).
- **Email OTP Login** off by default ([[otp-login]]).
- **The admin theme** is the store's own "pardes" theme.
- The **MANAdev** and **Templates Master** menus are hidden; their settings are still in System > Configuration.

A value saved in System > Configuration overrides these defaults.
