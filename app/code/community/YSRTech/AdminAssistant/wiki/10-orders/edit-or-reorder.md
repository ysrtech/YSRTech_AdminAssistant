---
title: Change an order, or reorder
category: Orders
sort: 150
---
OpenMage cannot change an order in place. **Edit** on an order makes a new order with the same items (numbered like `100000123-1`) and cancels the original when the new one is submitted. It is only offered while the order is not invoiced.

To change a paid order, the usual way is:

1. Refund what is no longer wanted ([[refund-an-order]]), or
2. Create a new order for what is added ([[create-an-order-for-a-customer]]).

Addresses can be corrected without editing the order: **Edit** beside the billing or shipping address on the order page.

**Reorder** starts a new order with the same items for the same customer.
